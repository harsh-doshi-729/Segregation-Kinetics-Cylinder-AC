This directory contains scripts and files relating to the simulations performed for checking whether a mixed state of polymers has concantenated polymers or not.
Polymers are said to be concantenated if they are interlocked with one another or if their subloops are interlocked with one another. Such a state of polymers has an additional topological constraint that might affect their segregation kineticsc, and hence we do not want out polymers to be concatenated.

The function of the scripts in the Scripts/ folder are explained below:
copyShrinkExecute.sh: Copies the last snapshot (mixed state) of the shrink-relax simulation performed in the Create_Initial_States/ directory to a corresponding subdirectory within Check_Concatenation/
execute.sh: Runs simulation(s) starting from the mixed state to determine whether the polymers are concantenated.
predict_concantenation.sh: Uses the output generated by the previous simulation and the predict_concatenation.c script to give a yes/no answer for whether the particular mixed state has concatenated polymers.
segregate.lammps: Runs a LAMMPS simulation to check whether the two polymers are concantenated.
separate_segregate.lammps: Runs LAMMPS simulations for each of the two polymers in the mixed state to check whether they have concantenations between their internal loops.

Each of these bash scripts takes certain arguments which can be found by simply running these scripts.
